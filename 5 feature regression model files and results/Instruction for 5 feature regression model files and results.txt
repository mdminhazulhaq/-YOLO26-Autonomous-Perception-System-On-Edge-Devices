### Model

Model Architecture
class DistanceRegressionModel(nn.Module):

    def __init__(self):
        super().__init__()

        self.network = nn.Sequential(

            nn.Linear(4, 16),
            nn.ReLU(),
            nn.Dropout(0.2),

            nn.Linear(16, 32),
            nn.ReLU(),
            nn.Dropout(0.2),

            nn.Linear(32, 16),
            nn.ReLU(),
            nn.Dropout(0.2),

            nn.Linear(16, 1)

        )

    def forward(self, x):
        return self.network(x)




| Parameter     | Value                |
| ------------- | -------------------- |
| Architecture  | 4 → 16 → 32 → 16 → 1 |
| Activation    | ReLU                 |
| Dropout       | 0.2                  |
| Loss          | MSELoss              |
| Optimizer     | Adam                 |
| Learning Rate | 0.001                |
| Epochs        | 100                  |
| Parameters    | 1,169                |
